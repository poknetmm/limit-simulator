# 한도 시뮬레이터

대출 한도 전략을 단계(도형)로 그려 계산해 보는 웹 시뮬레이터입니다. 로그인한 팀원만 쓸 수 있습니다.

- **가상 데이터 전용** — 고객 개인신용정보를 입력하거나 올리지 마세요. 올린 데이터는 브라우저 안에서만 계산하고 서버에 저장하지 않습니다.
- 이 저장소에는 빈 도구만 있습니다. 전략은 로그인 뒤 서버에서만 읽힙니다.
- 포함 라이브러리: SheetJS Community Edition 0.20.3 (Apache-2.0, `lib/LICENSE-sheetjs.txt`), supabase-js 2.117.2 (MIT, `lib/LICENSE-supabase.txt`)
